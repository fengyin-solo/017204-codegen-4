## 首屏加载体验

数据与图表就绪前，页面展示玻璃质感骨架占位块与加载动画，覆盖层面板实时概览
5 个区块的加载状态（核心指标 / 漏斗图 / 雷达图 / 战略矩阵 / 速赢清单）。
区块就绪后以统一节奏（0.45s 淡入 + 0.35s 高度过渡）平滑替换骨架，骨架随后从
DOM 彻底移除；背景动画、网格覆盖层与粒子效果层在整个过程中连续播放，不闪动、
不重叠。滚动条与玻璃卡片观感保持不变，窄屏 / 宽屏过渡节奏一致。

- 区块加载超过 8 秒判定超时，或网络断开时：已加载区块保持不变，失败区块在概览中
  标红，面板提供「重新加载」；浏览器网络恢复（online）时自动重试。
- 重试会先销毁旧图表实例、清空旧内容与占位块，再重新走完整加载流程，刷新后不残留占位。

联调 / 演示参数：

| 参数 | 作用 |
|------|------|
| `?fast=1` | 各区块快速就绪（约 0.2s），便于快速验证 |
| `?fail=funnel` | 模拟指定区块超时失败（可选值：stats / funnel / radar / matrix / quickwins） |

# 第一步：构建三阶段成熟度模型 (The Framework) 
你必须严格按照以下三个阶段作为矩阵的**列 (Columns)**： 

* **阶段 1: 沉睡通讯录 (Digital Notebook)** 
* *特征：* 会员=手机号。只有交易记录，无互动，权益仅限积分兑换，画像模糊。 
* *焦点：* **资产留存** (解决“有数据无运营”的问题)。 
* **阶段 2: 社交连接体 (Social Connection)** 
* *特征：* 建立微信/企微私域，有明确等级(Tier)和付费会员(Plus)。开始做人群标签(Tagging)，内容千人千面。 
* *焦点：* **活跃与复购** (解决“有私域无转化”的问题)。 
* **阶段 3: 智能价值网 (AI & Value Network)** 
* *特征：* 算法驱动。预测LTV，自动化营销(MA)接管触达，全域数据打通(CDP)，实现“单客价值最大化”。 
* *焦点：* **预测与生态** (解决“增长天花板”的问题)。 

--- 

# 第二步：定义六大运营维度 (The Rows) 
矩阵的**行 (Rows)** 必须覆盖零售会员运营的核心闭环： 

1.  **全域获客 (Acquisition):** 公域(天猫/抖音)转私域路径、门店包裹卡、裂变机制。 
2.  **权益体系 (Rights & Tiers):** 等级成长值、付费会员(Plus)设计、积分消耗场景。 
3.  **私域触点 (Touchpoints):** 1v1 私聊 S.O.P、社群运营节奏、视频号/直播联动。 
4.  **数据画像 (CDP & Tagging):** 静态标签 vs 动态行为标签 vs 预测标签 (RFM模型)。 
5.  **自动化营销 (MA & Lifecycle):** 关键时刻(MOT)自动触达 (如：生日、满月复购、流失预警)。 
6.  **工具基建 (MarTech Stack):** 支撑上述动作的数字化底座。

2.  **核心组件：【会员战略全景矩阵大表】 (The Grand Matrix)**

* **内容填充：** 每个单元格需包含 **关键SOP** + **必备工具**。 
* **工具推荐纪律：** 必须包含 **国际标杆** (Salesforce, Adobe) 和 **中国本土主流** (微盟, 有赞, 驿氪, 神策, 腾讯企点, 句子互动)。

3.  **辅助组件：**
